## My Project Proposal

**What are you building? One or two sentences describing your project.**
- I am building a Flask web application called Men’s Tennis Singles Explorer that allows users to search tennis players, view player match summaries, compare players, and explore tournament data using the Sportradar Tennis API.
**Why? What motivates you to build this? What problem does it solve?**
- I am motivated to build this because I am interested in analysing the matches before being played and wanted to apply Python to may lead to a better prediction of match result. The project solves the problem of making player and match data easier to search, compare, and visualize in one place.
**MVP vs. Stretch Goals: What is the minimum working version? What would you add if you have time?**
- The minimum working version (MVP) includes player search, player match summaries, win/loss charts, player comparison, and tournament browsing. If I have time, I would add player photos, more historical player, and a rough prediction of who might win next match 
**What don't you know yet? Be honest about uncertainties - new libraries, APIs, concepts you need to learn.**
- I am still learning how to work with all available endpoints in the Sportradar API, how much historical player data the API provides, and how to improve handling of inconsistent API responses. I  also need to learn more about integrating additional endpoints.
